# Experiment Datasets

Included CSV files were copied from the uploaded course ZIP:
- `eda_student_performance_500.csv`
- `house_price.csv`

The uploaded ZIP did not contain local image archives for MNIST, Fashion-MNIST, or CIFAR-10.
The supplied TensorFlow/Keras experiment scripts load these datasets using the built-in
`tf.keras.datasets` loaders when run with an internet connection.
